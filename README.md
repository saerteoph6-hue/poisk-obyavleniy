# Поиск объявлений — Android

Бесплатное неофициальное Android-приложение: открывает живой поиск на Авито по всей России с фильтрами цен, позволяет сохранять ссылки и считать потенциальную прибыль.

**Это не парсер и не статистика реальных продаж.** Поиск загружается непосредственно с сайта Авито; сайт может ограничивать встроенный просмотр. В этом случае используйте кнопку «В браузере».

## Сборка APK

Откройте **Actions → Build Android APK**, выберите последний успешный запуск, скачайте архив **poisk-obyavleniy-debug-apk** из раздела Artifacts и извлеките **app-debug.apk**. GitHub Actions запускается автоматически при изменениях в ветке main; вручную его можно запустить через **Run workflow**.

Для самостоятельной сборки нужны JDK 17, Gradle 8.9 и Android SDK 35: `gradle :app:assembleDebug`.

В приложении нет сервера, платного API или доступа к контактам. Ссылки сохраняются локально на устройстве. Приложение не связано с Авито.
