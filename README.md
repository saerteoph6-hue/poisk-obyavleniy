# Жесты PRO — Android / Samsung Galaxy A36

Сделай скриншот проведя **двумя пальцами вниз** в любом обычном приложении. Снимки сохраняются в Галерею / Pictures/Screenshots. Никакого сетевого доступа.

## ВАЖНО
Android требует специального режима «Изучение касанием» для распознавания многопальцевых жестов по всему экрану. В этом режиме одно касание выбирает элемент, двойное открывает. Это сильно меняет управление. Режим можно выключить в приложении или через Настройки → Специальные возможности → Установленные приложения → Жесты PRO. Не включай его, если не согласен с таким изменением.

## APK
После успешного запуска GitHub Actions **Build Zhesty PRO APK** скачай артефакт **Zhesty-PRO-debug-apk** и извлеки файл app-debug.apk. В Android включи службу доступности «Жесты PRO — скриншот», затем включи переключатель в самом приложении.

Если служба недоступна после установки APK, открой сведения о приложении → ⋮ → «Разрешить ограниченные настройки», вернись в настройки доступности и включи службу. Защищённые окна не снимаются.

Сборка: JDK 17, Gradle 8.9, Android SDK 35: gradle :app:assembleDebug.
