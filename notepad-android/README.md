# Мои заметки

Простой офлайн-блокнот для Android.

Возможности:
- создание и редактирование заметок;
- автоматическое сохранение;
- поиск по заголовку и тексту;
- закрепление важных записей;
- удаление заметок;
- локальное хранение без регистрации и интернета.

## Сборка APK

Проект собирается в GitHub Actions при изменениях в ветке `notepad-android`.

Откройте **Actions → Build Moi Zametki APK**, выберите последний успешный запуск и скачайте артефакт **moi-zametki-debug-apk**. Внутри находится `app-debug.apk`.

Для локальной сборки нужны JDK 17, Gradle 8.9 и Android SDK 35:
`gradle :app:assembleDebug`.
